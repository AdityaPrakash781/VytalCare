# Personal Contributions (Aditya Prakash)

I played a key role in shaping VytalCare’s user experience, conversational intelligence, and product direction, contributing across UI/UX design, feature ideation, and core AI system implementation.

## UI / UX Enhancements

- Proposed and implemented multiple UI/UX improvements across the dashboard, chatbot, and health-tracking views to improve usability, accessibility, and visual clarity.

- Improved layout structure, spacing, and visual hierarchy for health metrics, charts, and cards to reduce cognitive load.

- Refined interaction flows to better support non-technical users and elderly users, focusing on preventive healthcare use cases.

- Ensured design consistency across components to maintain a cohesive, health-focused design system.

## Product Feature Ideation

- Contributed several user-centric feature ideas, many of which were implemented or incorporated into the system roadmap:

- Google Calendar Integration for syncing medication reminders and health events.

- User Profile Section for managing personal details, caregiver information, and emergency contacts.

- Color-Blind Accessibility Mode to improve inclusivity using contrast-safe color palettes.

- Camera-Based Prescription Reading concept leveraging OCR + AI to automatically extract medication details from prescriptions.

## Conversational AI & Chatbot Ownership

- Designed and implemented the entire conversational AI chatbot system (excluding voice input).

- Built context-aware health conversations using Gemini-powered responses.

- Implemented Retrieval-Augmented Generation (RAG) for personalized and medically relevant guidance.

- Integrated Firestore-backed persistent chat history with role-based message tracking.

- Connected chatbot reasoning with short-term and long-term agent memory, enabling longitudinal health awareness across sessions.

- Defined chatbot conversation flows, safety handling, and structured responses aligned with preventive healthcare principles.

## System-Level & Product Thinking

- Actively participated in system design and feature prioritization discussions, balancing technical feasibility with real-world healthcare impact.

- Helped align frontend UX decisions with backend architecture, data models, and agent workflows.

- Contributed to ethical, reliable, and scalable AI design considerations for health-focused applications.

## Summary

Owned major portions of VytalCare’s UI/UX design, chatbot and conversational AI system, and product feature ideation, ensuring the platform remains usable, scalable, and aligned with preventive healthcare goals.
